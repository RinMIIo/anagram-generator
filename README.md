# Anagram Generator

Настольное приложение на Python (Tkinter): ищет анаграммы слов по русскому словарю, перебирает перестановки чисел и содержит мини-игру, где нужно собрать слово из перемешанных букв.

Проект учебный, сделан для недели науки.

## Возможности

- **Словарь анаграмм.** Вводишь слово, и программа выводит все слова из словаря, составленные из тех же букв.
- **Перестановки чисел.** Если ввести число (из двух и более цифр), программа покажет все его уникальные перестановки.
- **Игра.** 6 раундов, в каждом программа загадывает слово и перемешивает его буквы. Длина слов растёт от раунда к раунду: 4, 4, 5, 5, 6, 6 букв. Засчитывается и загаданное слово, и любая другая допустимая анаграмма из словаря. В конце показывается результат и все ответы.

## Как это работает

При запуске программа читает словарь и группирует слова по ключу, то есть по отсортированным буквам слова. Слова с одинаковым ключом являются анаграммами друг друга. Поэтому поиск анаграмм сводится к одному обращению к словарю (`dict`), а не к перебору всех слов.

## Словарь

Файл словаря в репозиторий не входит. Программе нужен файл `russian.txt`: русские слова, по одному в строке, кодировка UTF-8.

Я использовала словарь из репозитория [danakt/russian-words](https://github.com/danakt/russian-words) (лицензия MIT). В нём около 1,5 миллиона записей, включая все грамматические формы слов, поэтому среди анаграмм могут встречаться необычные формы. Исходный файл хранится в кодировке windows-1251, перед использованием его нужно перевести в UTF-8.

Как подготовить словарь:

1. Скачай `russian.txt` из репозитория выше.
2. Преобразуй его в UTF-8 (нужен установленный Python):

```
python -c "open('russian_utf8.txt','w',encoding='utf-8').write(open('russian.txt',encoding='cp1251').read())"
```

3. Переименуй результат в `russian.txt` и положи рядом с `anagram_app.py`.

## Запуск

1. Установи Python 3.10 или новее. Tkinter входит в стандартную поставку Python для Windows.
2. Подготовь словарь, как описано выше.
3. Запусти:

```
python anagram_app.py
```
